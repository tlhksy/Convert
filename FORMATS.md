# What each output format loses

Generated by `audit/make_formats.py` from the audit measurements; do not
edit by hand. Every row corresponds to an observation made by reading the
converted file with an independent library, not to a claim about what the
converter intends.

Taxonomy version 1.2. 100 conversions, 113 losses, 78 reported.

**Reported** means the conversion log named the loss while it happened. A
loss that is not reported is not necessarily worse, but the user has no way
to know it occurred.
